## 命令

| 命令 | 做什么 |
| --- | --- |
| `just check` | 只检查不改文件 |
| `just test` | 单元和集成测试 |
| `just e2e` | 端到端测试 |
| `just gen` | 改了操作的输入输出后重新生成类型 |
| `just dev <端>` | 开发模式跑一个端 |

## 质量关卡

提交前 `just ci` 必须通过。改了操作的输入输出要 `just gen` 并提交生成的文件。
